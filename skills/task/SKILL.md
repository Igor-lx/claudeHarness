# Начало задачи: ярус входа

Полный вход в проект стоит около двух тысяч строк. Для рефактора слоя это
дёшево, для вопроса про одну константу — абсурдно. Этот скилл задаёт, что
читать под конкретную задачу, и не даёт ни занизить ярус, ни завысить.

## Шаг 1. Определи класс задачи

Класс определяется **по тому, что будет в ответе**, а не по глаголу, которым
попросили. Признак: в ответе есть хотя бы одно утверждение о том, как код себя
ведёт, что означает или верно ли сделан. При наличии такого утверждения класс —
не A, независимо от формулировки просьбы.

| Класс | Признак |
| --- | --- |
| **A. Расположение** | ответ — «где лежит», «что уже решено», без утверждений о поведении |
| **B. Объяснение узла** | ответ описывает поведение одного файла или хука |
| **C. Багфикс** | место известно, поведение меняется точечно |
| **D. Рефактор** | код переезжает, поведение обязано остаться прежним |
| **E. Новое** | появляется файл, ветка, проп или модуль |

## Шаг 2. Прочитай ровно это

- **A** — раздел «Проект на одной странице» в `.context/00-map.md`, затем нужный
  раздел карты по адресу.
- **B** — то же, плюс `node .claude/work/tools/graph.mjs brief <путь>`, затем сам файл и
  его тест **целиком и дословно**.
- **C** — то же, плюс `node .claude/work/tools/graph.mjs plan <путь>`, плюс записи
  `07-invariants.md` и `09-decisions.md` по этой области.
- **D** — полный вход (`CLAUDE.md`, `01-facts.md`), плюс `plan` и `blast`.
- **E** — полный вход, плюс `.context/10-idioms.md` и раздел «Как заводится
  новый узел» в `.claude/work/rules/code.md`.

Ярус занижать нельзя: если по ходу выяснилось, что задача шире выбранного
класса, недостающее дочитывается и это называется в отчёте. Завышать тоже
нельзя: прочитанное сверх необходимого результата не даёт, и завышение
называется в отчёте так же.

## Шаг 3. Собери радиус одним вызовом

```
node .claude/work/tools/graph.mjs plan <путь>
```

Отдаёт сразу: радиус прямой и транзитивный, парную копию (её правят в той же
правке), тесты, обязанные покраснеть, записи базы под обновление, якорь
документации. Это заменяет связку `brief` + `blast` + чтение карты руками.

## Шаг 4. Помни, чем работа закончится

- правка кода — тесты в том же заходе, F1 на каждом (сломай, убедись, что
  краснеет именно он);
- **сверка с планкой качества до прогона** — прочитать свой дифф по разделам
  поимённо по ядру политики качества и живым применимым разделам, а не «я помню»; не сошлось — переделать. В отчёте
  об этом стоит отдельная строка;
- **попутные находки** — что попалось по дороге в коде, тестах, базе, правилах
  или в инструменте, чинится этим же заходом и называется в отчёте отдельно.
  Чинится **класс**, а не пример: правка под один случай оставляет остальные
  случаи того же класса без изменений. Машинной проверки у этого пункта нет:
  находку, которую не записали, не обнаруживает ни одна сверка;
- **БД** (`.context/**`, «что и где» для следующей сессии) и **документация**
  (`docs/**`, ADR, README — «почему» для человека) правятся вместе с кодом и
  подтверждаются в отчёте **порознь**, двумя утверждениями. Кодом здесь
  считается всё: модули, тесты, стили. Как писать документацию и комментарии —
  `docs/CONVENTIONS.md`. **Прибавилась возможность, видная снаружи, — строка в
  витрине `docs/FEATURES.md`**, словами продукта, а не кода: витрина отвечает
  тому, кто взял компонент впервые, и правится при любом прибавлении поведения,
  а не только когда появилось «почему»;
- **`node .claude/work/tools/graph.mjs tested`** перед отчётом: он и спросит про тесты
  тронутых файлов, про записи базы и соседей, про документацию и про то, задета
  ли область смоука;
- **`npx stryker run --mutate "<новые и изменённые файлы>"`**, если правился
  код: узел закрывается в том контексте, в котором писались его тесты. Долг
  показывает `node .claude/work/tools/graph.mjs mutated`;
- **`npm run check`** — весь обязательный набор одной цепочкой: типы, линт,
  формат, тесты, сверка базы;
- **`/code-review` на правку узла до коммита** — прогон с кодом возврата ноль
  означает «поведение не сломано», а не «узел устроен верно»;
- **`/run`, если правка видна на экране** — ни база, ни тесты, ни смоук не
  отвечают, как это выглядит и ощущается;
- широкое сметание («найди все места, где…») — агентом `Explore`, чтобы выдача
  не оседала в основном контексте. Решает разработчик, но **предлагаешь ты**:
  форма опознаётся по трём условиям сразу — десятки файлов, на выходе нужен
  список, а не дословный текст, и где смотреть заранее неизвестно. Не выполнено
  одно — обычный поиск дешевле, и предлагать нечего;
- `commit`, `push`, `deploy` — только по прямой команде.

## Правило остановки

Поиск и сверка прекращаются, когда следующий шаг перестал менять ответ. Третий
источник подряд повторяет известное, уточнение меняет формулировку, но не
решение, — значит хватит. Продолжать после этого не тщательность, а работа,
результат которой выбрасывается.
