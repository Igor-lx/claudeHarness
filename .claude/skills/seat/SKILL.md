# Посадить обвязку

Посадку делает команда, а не этот текст и не `seat/seat.md`. Здесь — что
звать, как ответить на каждый исход и чего не делать. Почему посадка
устроена так, — `seat/seat.md`, раздел «Посадка — одной командой, сценариев
три»; читают его, только если разработчик спросил «почему».

## Что звать

Из корня папки, где лежит `.claude`, — она же рабочая папка сессии;
стартовали выше — `entry.md`, пункт 2 порядка входа:

```
node .claude/tools/graph.mjs seat .
```

Исход называет первая строка вывода после счёта файлов обвязки.

## Исходы

| Вывод | Что делать |
| --- | --- |
| `ПОСАДКА НЕ ЗАВЕРШЕНА. Фаза 1 закончена.` | отчёт передать разработчику дословно: он написан для человека. Задать вопрос фазы 2 из этого же отчёта, по ответу — раздел «Фаза 2. Завершение посадки» `seat/seat.md`, только его |
| `=== Посадка ждёт слова: стек приводится к связке ===` | показать план — пакет, было, станет — и задать один вопрос: привести? «Да» — та же команда с ключом `--apply`. «Нет» — посадки не будет: знакомый проект без приведения не сажается; сказать это прямо |
| `Среда ниже проверенной связки` либо Node.js нет вовсе | `seat/seat.md`, шаг 0: план загрузчика одной строкой, загрузчик, затем та же команда. Вопроса нет |
| `Незакоммиченное в проекте` либо `Живой проект без репозитория git` | передать разработчику дословно: закоммитить своё — его решение. Своё он коммитит сам |
| `=== Посадка уже сделана ===` либо `Обвязка здесь уже посажена` | сказать, что посадка уже есть, и ничего не делать |
| `ЧТО ОБВЯЗКА НЕ ВИДИТ` в отчёте чужого проекта | передать два пути, выбирает разработчик. «Переставить» — команда, которую назвал сам отчёт, затем снова `seat .`; «перейти» — работа разработчика, сессия её не начинает |
| прочий `=== Посадка не собрана ===` | причину передать дословно и остановиться |

## Чего не делать

- **`--apply` — только после «да»** на показанный план: он меняет
  зависимости проекта.
- **`--packages` и `--with` не подставлять.** Первый — ключ мастерской,
  второй — ответ разработчика на «переставить».
- **Код, конфиги и историю проекта не трогать** — ни правкой, ни коммитом,
  ни удалением: что положено, кладёт команда, остальное делает разработчик.
- **Прозу посадки целиком не читать.** Исход называет вывод команды, нужный
  раздел назван в таблице выше.
