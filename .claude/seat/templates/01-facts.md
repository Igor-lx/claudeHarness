Проект целиком: базовая линия проверок, инструменты, состав скиллов, применимость
разделов планки. Читается безусловно, при каждом входе.

## Указатель документации

Документ, которого нет в этой таблице, находит только тот, кто уже знает о его
существовании. Состав сверяется: файл в `docs/`, не названный здесь, роняет
прогон. Новый документ — новая строка, тем же заходом.

| Нужно понять | Файл |
| --- | --- |
| как здесь пишут: имена, границы, формы записи | `CONVENTIONS.md` |
| что продукт умеет — списком возможностей | `FEATURES.md` |

## Применимость разделов планки качества

Ядро планки (A–J) действует всегда. Разделы K–U объявляются живыми или
неприменимыми **по замеру, а не по представлению**: предмет каждого инструмент
ищет на диске сам, и раздел, объявленный неприменимым при найденном предмете,
завершает прогон ненулевым кодом.

Вторая графа читается дословно: `да` — раздел живой, любое другое слово —
неприменим, и тогда третья графа обязана назвать причину.

| Раздел политики | Применим | Чем подтверждается |
| --- | --- | --- |
| K. Внешние данные | нет | кода нет: ни запроса, ни хранилища, ни переменных окружения; зависимостей тоже нет |
| L. Асинхронность и конкурентность | нет | кода нет: ни промиса, ни таймера, ни отмены |
| M. Модель рендера фреймворка | да | каркас на React приехал семенами: разметка, монтирование, строгий режим |
| N. Анимация и взаимодействие | нет | ни кадров, ни указателя, ни переходов: анимировать нечего |
| O. Стили и адаптивность | нет | файлов стилей ноль, библиотек стилей в зависимостях нет |
| P. Доступность | да | разметка есть с первого дня, и её роли уже проверяются тестом корневого компонента |
| Q. Безопасность | нет | ни вставки разметки строкой, ни внешних адресов, ни санитайзеров |
| R. Зависимости и поставка | да | зависимости разработки стоят с посадки: компилятор, линтер, форматтер, раннер. Поставки пока нет, но предмет раздела уже на диске |
| S. Наблюдаемость | нет | ни запуска, ни доставки, ни библиотек логирования: наблюдать нечего |
| T. Интернационализация | нет | текстов для человека в коде нет, форматирования по локали тоже |
| U. Конвейер проверок | нет | конвейера нет: ни одного файла описания сборки на сервере |
